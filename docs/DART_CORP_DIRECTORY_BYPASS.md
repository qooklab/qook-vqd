# 기아 DART 기업목록 20초 시간 초과 — 다운로드 의존 제거

## 확인된 오류

사용자가 실제 화면에서 제공한 오류:

```text
기아: 수집 지연: DART 기업목록 조회 응답 시간 초과 (20초).
잠시 후 다시 시도해 주세요. (자동 재시도 후 실패)
```

이 오류는 기아 재무제표 요청 이전의 전체 기업목록 다운로드 단계에서 발생했다. 서버 실행 시간을 늘리거나 같은 큰 파일을 재시도하는 것만으로는 해당 의존성을 해결하지 못했다.

## 수정

- DART의 공개 기업 검색을 6자리 종목코드로 조회하고, 검색 결과의 종목코드가 정확히 일치하는 행의 8자리 기업코드를 추출했다.
- 등록 30종목을 2026-11-04에 대조했다. 삼성전자우는 삼성전자와 같은 발행 법인이므로 29개 법인 기록에 해당한다.
- 출처별 조회 URL과 결과는 `docs/data/dart-corp-codes.json`에 보관했다. 기아 000270 → 00106641, 기업은행 024110 → 00149646이다.
- 실행 시 `lib/dart-corp-codes.ts`의 검증된 매핑을 먼저 사용한다. 등록 종목에서는 기업목록 ZIP과 기업코드 DB 조회가 모두 필요 없다.
- 재무제표와 점수는 계속 실제 OpenDART API/캐시를 사용한다. 재무 수치나 점수를 정적으로 넣지 않았다.
- 향후 신규 종목 또는 법인 변경이 있을 때 `node scripts/update-dart-corp-codes.cjs`로 공식 검색과 재대조한다. 정확히 한 종목이 일치하지 않으면 저장하지 않고 실패한다. 공개 검색 HTML은 런타임 의존성이 아니다.
- 검증 매핑에 없는 코드에는 기존 캐시·전체 기업목록 경로를 유지한다.

공식 출처 예시: [DART 기아 기업 검색](https://dart.fss.or.kr/dsae001/search.ax?textCrpNm=000270), [DART 기업은행 기업 검색](https://dart.fss.or.kr/dsae001/search.ax?textCrpNm=024110). 기업코드와 종목코드의 정의는 [공식 OpenDART 개발가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019018) 참고.

## 검증

- 실제 FSS 공개 검색: 29개 법인·30종목의 정확한 종목코드 매칭 완료.
- 테스트에서는 네트워크와 기업코드 DB 조회가 호출되면 즉시 실패하도록 설정한 뒤, 모든 등록 종목의 findCorp가 올바른 기업코드를 반환하는 것을 확인했다.
- 기존 오류 복구·CFS/OFS·캐시·재시도 테스트를 포함해 30개 통과.
- 타입 검사와 프로덕션 빌드 통과.
- 작업 환경에 API 키가 없어 실제 재무제표 수집 성공 여부는 운영 배포 후 확인해야 한다. 이번 수정으로 등록 종목이 'DART 기업목록 조회 시간 초과' 경로에 진입하지 않는 것은 테스트로 검증했다.
