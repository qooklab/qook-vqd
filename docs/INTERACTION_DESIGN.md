# 인터랙션 디자인

metic.studio에서 참고한 편집형 타이포·촉각적 인터랙션을 Qook VQD의 화면에 맞게 구현했다. 참고 사이트의 이미지·코드·음원은 복제하지 않는다.

## 적용 범위

- 페이지 이동: Next Link의 기본 동작으로 즉시 이동한다. 화면 덮기·본문 이동·홈 첫 화면 등장 효과와 인위적 대기 시간을 제거했다. 수정키·새 탭·외부 링크 등 브라우저 기본 동작을 가로채지 않는다.
- 메뉴: 전체 화면 메뉴, 항목별 순차 등장, 호버/포커스에 반응하는 번호·궤도 미리보기. 배경은 inert로 비활성화하고 스크롤을 잠근다. Escape 닫기, Tab 순환, 닫은 뒤 원래 컨트롤에 포커스 복원을 지원한다.
- 소리: Web Audio의 사인파로 짧은 호버·클릭·전환·토글 소리를 직접 합성한다. 외부 음원과 자동 재생 배경 음악은 없다. 첫 실제 터치/클릭/Enter/Space 후 오디오를 활성화한다. 호버 소리는 100ms 간격 제한. 탭이 숨겨지면 정지하고 다음 사용자 입력으로 재개한다.
- 설정: Sound 버튼의 On/Off만 `qook-sound` 로컬 저장소 키로 기억한다. 이 키에는 인증키나 투자 정보가 없다. X-ray는 현재 화면에서만 유지한다.
- 마우스: 기본 커서를 유지하면서 빨간 포인터 피드백, 링크·버튼 호버 링, 주요 버튼의 작은 자석 효과. 홈 계기판은 마우스 위치에 따라 입체 기울기와 바늘 방향이 달라진다.
- 스크롤: 상단 진행선, 화면에 들어오는 섹션과 행의 짧은 등장, 점수 막대의 시작 애니메이션. 숫자·점수 값 자체는 연출을 위해 바꾸지 않는다.
- X-ray: 레이아웃 그리드와 요소 윤곽, 마우스 주변 반전 렌즈를 표시한다. 모든 장식 레이어는 포인터 이벤트를 가로채지 않는다.

## 접근성·모바일

- 터치/굵은 포인터에서는 커서·자석 효과를 사용하지 않는다. 모바일에서는 간결한 헤더와 전체 메뉴를 통해 탐색한다.
- `prefers-reduced-motion: reduce`에서는 전환 가로채기·큰 등장·연속 애니메이션·커서를 생략하고 내용은 즉시 표시한다.
- 소리를 끄거나 오디오 API가 차단되어도 탐색과 데이터 기능은 유지한다.
- 소리·X-ray·메뉴 컨트롤에 상태와 접근 가능한 이름을 제공한다. 데이터 수집·평가·인증 경로는 변경하지 않는다.

## 검증

`node --test scripts/test-experience.cjs`

사용자 입력 전 무음, 합성 음량 상한, 호버 호출 제한, API 차단 시 정상 동작을 검증한다. `npm run build`로 타입 및 프로덕션 빌드를 확인한다.
