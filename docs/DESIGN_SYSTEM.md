# Qook VQD — Cool Research

이번 화면의 기준은 밝은 회색 캔버스, 흰 데이터 표면, 잉크색 본문, 선택과 점수에만 사용하는 블루다. 사용자가 새 컬러 방향을 요청해 기존 올리브 팔레트와 자동 다크 모드를 대신하는 라이트 중심 디자인으로 변경했다.

## 화면 구성

```text
qook / VQD     종목 리서치   평가 기준   데이터 관리

종목 리서치.                              최근 수집 / 관리
짧은 화면 설명
관찰 종목 30  |  시세 수집 30/30  |  전체 평가 완료 0

전체 종목                                     점수 가이드
종목 검색                          전체 / 완료 / 일부 / 미평가
점수 해석 안내
종목·코드 | 수집가 | PER | PBR | 확인 점수 | 매수가 | 수집일
```

- 메인: 소개 배너와 요약 카드를 없애고 얇은 현황 줄과 표로 구성한다.
- 종목 상세: 종목 이름·가격·확인 점수·평가 범위를 구분한다. 미평가를 낮은 점수로 단정하지 않는다.
- 평가 기준: 긴 글을 읽는 문서형 구성. 색면과 둥근 카드를 반복하지 않는다.
- 데이터 관리 `/manage`: 한투 시세와 DART 재무정보를 가져오는 기존 도구를 별도 화면으로 이동한다. 상단 메뉴와 메인 관리 링크에서 접근한다.
- 모바일: 표의 수치를 종목별 묶음 목록으로 변환한다. 380px 이하에서는 메뉴와 상태 필터를 다시 배치한다.

## 타이포그래피·컴포넌트

시스템 한글 산세리프 한 계열을 사용한다. 제목 30–36px 상당, 본문 14–15px 상당, 보조 글자 최소 12px 상당의 rem 단위. 가격과 점수는 고정폭 숫자로 정렬한다. 경계는 1px, 반경은 입력과 버튼에 4–6px만 사용하고 데이터 영역에는 그림자를 사용하지 않는다. 버튼·필터·메뉴는 키보드 포커스와 선택 상태를 갖춘다.

전체 100점 중 확인 점수와 평가 가능 배점을 따로 표시한다. 데이터 없음·일부 평가·전체 평가·검색 결과 없음·로딩·오류 상태를 유지한다. 가짜 시세·차트·수익률은 추가하지 않는다.

## 설계 참고

작업 영역이 내비게이션과 보조 정보보다 우선하도록 한 구성은 [Linear의 인터페이스 정리 과정](https://linear.app/now/behind-the-latest-design-refresh)을 참고했다. 색상과 금융 데이터 구성은 Qook VQD에 맞춰 별도로 설계했다.

## 검증

- `npm run typecheck`, `npm run build`, 수집·재시도 회귀 테스트 12개 통과.
- 브라우저에서 검색·정렬·종목 상세·데이터 관리 이동을 확인했다.
- 390px·320px에서 문서 가로 넘침 없음, 한투·DART 버튼 표시 확인.
- CSS 문법과 최소 글자 크기 검사 통과.
- 수집·인증·평가 로직과 기존 수동 갱신 컴포넌트는 수정하지 않았다.
- 실제 외부 API를 실행하지 않았으며 200% 글자 확대의 시각 검수는 미완료다.
