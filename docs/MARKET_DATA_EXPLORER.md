# 전체 종목 데이터와 개별 조회

- `/market`: 저장된 종목 마스터 전체와 선별 결과를 조회한다. 기본 표는 주권(ST)이며 필터로 마스터 전체를 포함한다. 시장·선별 상태·상세평가·종목명·코드 검색, 숫자 정렬, 50개 페이지, 필터 결과 CSV를 지원한다.
- `/api/market`: 저장된 선별 작업, `stock_latest`, DART 평가 근거를 읽는 전용 GET. KIS·DART 수집과 선별 재시작을 수행하지 않는다. DB 조회는 200개 코드 단위로 제한해 응답 1,000개 기본 제한으로 잘리지 않게 한다. 조회 실패는 503으로 전달하며 미평가로 위장하지 않는다.
- 1차 선별 순위와 20점 점수는 해당 회차 시세 기준이다. 별도 조회의 최신 주가는 표시하되 선별 상태·순위·점수를 바꾸지 않는다. 상세평가 확인 점수와 평가 가능 배점은 별도 열에 표시한다. 미수집 값은 null, 0점으로 대체하지 않는다.
- 각 종목의 펼침 화면에서 10개 평가 항목과 근거를 확인한다. 상세 페이지 `/stocks/[code]`는 선별되지 않은 주권도 공식 저장 마스터로 검증해 연다. ETF 등 비주권에는 DART 개별조회 링크를 제공하지 않는다.
- 상세 페이지 개별 조회는 기존 `CRON_SECRET` 인증 방식으로 `/api/refresh`를 사용한다. KIS 시세와 DART 통합평가를 각각 요청할 수 있다. DART 요청 시 저장 시세가 없으면 주가를 먼저 수집한다. 인증키는 컴포넌트 메모리에만 둔다.
- 선별 밖 종목은 상세 화면 열기만으로 외부 자료를 자동 수집하지 않는다. 버튼을 눌러 조회하며 기존 DART 캐시 정책(정상 7일, 일부 실패 15분)을 유지한다. 개별 조회가 자동 후보 목록을 변경하지 않는다.
- CSV는 UTF-8 BOM, 따옴표·줄바꿈 escaping, formula injection 방지를 적용한다. 내보내기에는 현재 필터·정렬 결과 전체가 포함된다.

검증: `npm run build`, `node --test scripts/test-market-data.cjs scripts/test-market-screen.cjs scripts/test-refresh-timeouts.cjs scripts/test-research.cjs`.
