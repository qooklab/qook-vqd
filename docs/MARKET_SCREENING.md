# 코스피·코스닥 전 종목 선별

기존 30개는 수동 관찰 목록이다. `/screen`은 기존 목록에 우선권을 주지 않고 코스피·코스닥 마스터 전체에서 같은 규칙으로 새 후보를 선정한다. KONEX는 이번 범위에 포함하지 않는다.

## 고정된 공개 기준 v1

1. 한국투자증권 공식 종목 마스터에서 6자리 영문·숫자 코드를 읽는다. 주권(ST) 중 보통주, 비스팩, 거래정지/관리/정리매매가 아닌 종목만 포함한다. ETF/ETN/ELW/외국주권(FS)/예탁증서(DR)/종류 미확인/우선주는 제외한다.
2. 마스터의 전일 시가총액 1,000억원 이상 및 제공 ROE 5% 이상. 빈 값은 통과시키지 않는다. 기업별 ROE 재무 기준일이 다를 수 있으므로 확정 동일 회계기간 비교로 표현하지 않는다.
3. 2번을 통과한 모든 종목의 KIS 시세·PER·PBR을 새로 수집한다. 0<PER<=15, 0<PBR<=1.5인 종목만 가격 조건 통과로 본다.
4. 기존 PER(10점)+PBR(10점) 산식으로 동일한 20점 1차 점수를 계산한다. 동점은 시가총액 내림차순, 코드 오름차순. 최대 30개이며 부족한 수를 채우기 위해 임의 종목을 넣지 않는다.
5. 대상 전체의 시세 조회가 성공해야 확정 후보를 공개하고 관찰 목록에 반영한다. 일부 오류가 남으면 잠정 목록으로 표시하고 기존 공개 관찰 목록을 유지한다. 음수/0/미제공 PER·PBR은 정상 수신 후 가격조건에서 탈락할 수 있으며, 통신 오류와 구분한다.
6. 후보의 배당·소각·3년 재무 등은 기존 DART 상세 평가로 따로 검증한다. 20점 선별 점수와 100점 상세 점수를 혼용하지 않는다. 1차 후보는 우량 배당주 인증이나 매수 추천이 아니다.

## 처리·복구

- `/api/screen` GET은 상태를 반환하고, 진행 중인 작업에 한해 응답 후 다음 묶음을 처리한다. 초기 GET에서 공식 두 마스터를 내려받고 작업을 만든다. 완료 작업을 익명 요청으로 재시작하지 않는다.
- 화면은 5초마다 확인한다. 현재 묶음은 최대 40종목, 최대 4개 동시 처리·시작 사이 250ms 간격, 반복 시작 예산 32초, 외부 KIS HTTP 요청별 8초 제한. 기능은 조회만 수행하며 주문 API를 사용하지 않는다.
- 진행 상태는 기존 `dart_financial_cache`의 특수 코드 `__market_screen_v1` JSON에 저장한다. 새 테이블/SQL 실행은 필요 없다.
- `checked_at` 비교 조건으로 55초 작업 임대를 원자적으로 취득한다. 임대 중 다른 요청은 중복 처리하지 않는다. 완료 결과 저장도 임대 버전을 확인한다. 프로세스가 중단되면 임대 만료 후 마지막 저장된 묶음부터 다시 처리한다.
- 조회 실패는 1회 더 재시도하고, 지속 실패는 partial 상태로 둔다. 초당 제한은 30초 냉각, 인증 문제는 중지 후 사유를 표시한다. 실패만 재시도/최신 마스터 전체 재수집은 인증된 POST에서만 허용한다.
- 탭을 닫거나 일시정지하면 현재 서버 묶음까지만 완료한다. 다시 열면 저장된 지점부터 재개한다. 별도 백그라운드 스케줄러가 탭 종료 후 전 종목 수집을 계속하는 것은 아니다.
- 확정 후 관찰 목록·수동 관리 목록·기존 시세 cron 대상은 새 후보로 바뀐다. 다음 새 선별 진행 중에는 마지막으로 확정된 목록을 유지한다. 초기 완료 전에는 기존 수동 목록임을 홈에 명시한다.
- 새 종목의 DART 기업코드는 공식 디렉터리에서 찾고 전체 디렉터리를 30일 캐시한다. 원래 30종목의 검증된 고유번호는 유지한다. 새 기업은 기업개황 업종코드를 확인해 금융업에 일반기업 부채비율을 적용하지 않는다. 업종 확인이 안 되면 건전성 점수를 채우지 않는다.

공식 고정폭 ASCII tail 길이는 코스피 227자·코스닥 221자(줄바꿈 제외)다. 이름을 포함한 파일은 CP949 호환 디코더로 읽으며 ZIP 예상 파일명·압축/해제 크기·형식을 검사한다. TLS 검증을 끄지 않는다. 마스터 다운로드 시각과 각 시세 수집 시작·종료 시각을 화면에 표시한다. 동시 시세나 전 종목 100점 평가를 완료한 것으로 표시하지 않는다.

검증: `node --test scripts/test-market-screen.cjs`. 실제 다운로드 파일에서도 파서 건수와 대표 종목의 이름·코드·ROE·시가총액을 대조한다. 기존 DART/수동 갱신 회귀 검사와 프로덕션 빌드도 실행한다.
