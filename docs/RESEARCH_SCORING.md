# 추가 평가 데이터 연결

## 수집·저장

- 상세 화면은 만료된 종목의 자료를 자동 수집한다. 목록은 응답 후 최대 3종목씩 순차 수집하고 최대 12회, 15초 간격으로 갱신한다. 방문이 없으면 이 작업은 실행되지 않는다. 기존 시세 cron의 일정은 변경하지 않는다.
- 관리 화면의 DART 버튼은 인증된 `POST /api/refresh`, `mode: research`로 통합 평가를 갱신한다. 기존 `mode: financial`은 호환 목적으로 유지한다.
- 연도 기준은 직전 완료 역년(2026년 실행 시 2025년), 사업보고서 `11011`이다. 올해 중간·분기 실적을 연간 배당으로 합산하지 않는다. 연초 전년 보고서가 미제출이면 미확인 사유가 표시된다.
- 정상 결과는 7일, 일부 원천 조회 오류는 15분 재사용한다. 연도가 바뀌면 다시 수집한다. 키·IP·호출한도 오류는 빈 결과로 캐싱하지 않는다.
- 기존 `dart_financial_cache.note` TEXT에 버전 1 JSON으로 원천 수치·기준 연도·공시번호·오류를 저장한다. 기존 캐시의 세 재무점수 컬럼과 `stock_latest`의 기존 평가 컬럼을 그대로 사용하므로 새 SQL 실행은 필요 없다. `lib/financial-score.ts` 단독 레거시 평가와는 캐시 포맷이 달라 다음 통합 평가 시 다시 수집한다.
- 화면은 캐시된 원천 사실과 최신 수집 시세를 결합한다. 배당수익률·모형 안전마진은 공시 캐시의 7일 TTL 때문에 과거 시세로 고정되지 않는다. 캐시 오류는 기존 화면을 막지 않고 안내한다.

## 평가 규칙

| 항목 | 자료·산식 | 배점 |
| --- | --- | --- |
| 모형 안전마진 | 추정가=min(수집가/PER×12, 수집가/PBR); 할인율=(1−수집가/추정가)×100. 양수 시세·PER·PBR 모두 필요. 모형 매수기준=추정가×0.8 | 할인율 ≥30/20/10/0/−10%에 15/12/9/6/3점, 미만 0 |
| 배당수익률 | `alotMatter`의 해당 주식 종류 최근 완료 연도 DPS/수집가×100 | ≥5/4/3/2/양수/0%에 10/8/6/4/2/0점 |
| 배당 지속성 | 최근 연도와 2년 전 사업보고서에 포함된 각 3개년 이력으로 5년 구성. 중복 연도는 최신 보고서 값 우선 | 5년 지급+비감소 10, 5년 지급+감소 8, 4/3/1~2/0년 지급 6/4/2/0점. 5년 전체 확인 필요 |
| 실제 소각 | `tesstkAcqsDspsSttus` 해당 주식 종류의 `총계.change_qy_incnr`. 분모는 `stockTotqySttus.istc_totqy`+당기 소각량 | 연간 소각비율 ≥3/2/1/양수%에 10/8/6/4점. 명시적 0주 0점 |
| 경쟁력 수익성 대리지표 | 같은 연결/별도 기준 3년 ROE=총 당기순이익/평균 기초·기말 총자본×100; 3년 최저 ROE | ≥15/10/5/양수/0이하%에 5/4/3/1/0점. 3년 전체 확인 필요 |

PER·PBR 및 기존 이익 안정성·비금융 부채비율·영업이익 CAGR 규칙은 유지한다. 금융업 재무 건전성은 일반기업 부채비율로 대체하지 않는다. 성장률은 흑자전환 시 CAGR의 비교가 어려워 미평가할 수 있다.

## 해석 한계

- 위 모형·임계값은 프로젝트의 자체 규칙이며 기업의 확정 내재가치·예상 배당률·공식 추천가격이 아니다. PER/PBR에서 역산한 EPS/BPS의 기준은 원천 시세 제공자 기준을 따른다.
- 주식분할·병합 및 특별배당을 별도로 조정하지 않는다. 주당배당금 추세와 소각비율 비교에는 이 영향이 있을 수 있어 화면에 명시한다.
- 시장지위·브랜드·전환비용을 자동으로 검증한 것으로 표현하지 않는다. 자동 경쟁력 점수는 3년 수익성만을 대리 측정한다.
- 보통주와 우선주를 구분하고, 복수 우선주 종류를 해당 티커에 확실하게 연결할 수 없으면 미평가한다. 배당/소각의 `-`, 빈 문자열, 조회 오류는 0이 아니다. 취득·결정·누적 소각액은 실제 연간 소각 수량을 대신하지 않는다.
- 공시 원문 링크와 상세 계산·누락 사유를 종목 상세에 표시한다. 100점 배점에서 확인된 점수 및 평가 범위를 함께 해석한다.
